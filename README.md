# Strategy Analysis Writer

把零散研究、访谈、数据和竞品材料，写成**结论先行、MECE 严谨、证据可追溯**的中文战略分析。

适用于：

- 竞品格局与产品路线
- 用户反馈与市场洞察
- 平台或生态健康度诊断
- 品牌叙事演进与战略换挡
- 面向管理层的决策稿

## 它解决什么问题

普通总结容易停在“材料很多、信息很全”，但没有回答决策者真正关心的问题：**结论是什么、为什么、接下来做什么。**

这个 skill 会强制建立四层结构：

1. 用一句话回答决策问题。
2. 用 MECE 的一级论据支撑总判断。
3. 用“事实 → 对比 → 机制”建立证据链。
4. 把洞察落到机会、风险、优先级和验证条件。

它还会区分：

- 对外叙事 vs. 真实兑现 vs. 市场验证
- 事实 vs. 估算 vs. 推断 vs. 假设
- 有功能 vs. 能跳转 vs. 能执行 vs. 能完成闭环
- 市场声量 vs. 用户行为 vs. 商业结果


直接提出战略分析任务，或显式调用：

```text
使用 $strategy-analysis-writer，把这批竞品资料整理成一份给管理层看的战略判断。
```

## 有 skill / 无 skill 对比

以下是同一输入的典型表现示意，用于说明方法差异，不是模型性能基准。

### 输入

```text
某技能市场有 11.1 万条技能，其中 56.2% 来自外部导入；
Top 1% 技能贡献 53% 安装量；约 87%–95% 用户从未安装技能；
57.5% 的技能上架后没有维护。请判断生态健康度并给出建议。
```

### 无 skill

> 该平台技能数量增长较快，但安装率和维护活跃度仍然偏低，头部效应比较明显。平台可以优化推荐机制、鼓励开发者持续维护，并通过运营活动提高用户安装意愿。

问题在于：结论偏泛、指标彼此并列，没有解释数字之间的因果关系，建议也缺少优先级。

### 有 skill

> **综合判断：该生态已经完成规模积累，但尚未形成有效循环，当前属于“虚假繁荣”。**问题不是技能数量不足，而是原创供给、真实需求和生态反馈三条链路同时断裂。
>
> 1. **供给规模主要由导入驱动，不能等同于社区创造力。**56.2% 来自外部导入，库存增长并未证明原创供给形成。
> 2. **真实需求尚未渗透。**约 87%–95% 用户从未安装技能；同时 Top 1% 吸收 53% 安装量，说明有限需求高度集中在头部。
> 3. **供需之间没有形成反馈循环。**57.5% 的技能上架后不再维护，创作者得不到使用反馈，用户也难以发现持续可用的新供给。
>
> **优先级：先修复“发现 → 安装 → 复用 → 反馈”的最短闭环，再扩大供给。**短期应以新技能安装率、30 天复用率和维护率作为北极星指标，而不是继续追求技能总量。

### 方法差异

| 维度 | 无 skill | 有 skill |
| --- | --- | --- |
| 起点 | 围绕材料做摘要 | 先定义决策问题 |
| 结构 | 观点平铺 | 总结论 → 一级论据 → 证据 |
| MECE | 现象、原因、建议容易混层 | 同层使用统一划分轴 |
| 证据 | 罗列数字 | 数字对应判断、基准和机制 |
| 结论 | “需要继续优化” | 明确定性、边界与置信度 |
| 建议 | 泛化动作清单 | 优先级、前置条件与验证指标 |
