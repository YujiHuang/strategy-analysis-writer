# 推理、MECE 与证据规范

在从零建立战略分析、重构长报告或面对相互冲突的材料时读取本文件。

## 1. 从决策问题而非主题开始

把“研究 AI 手机”“分析某平台生态”改写成可判断的问题，例如：

- 哪种产品路线更可能形成可持续差异化，依据是什么？
- 规模增长是否代表生态健康，最关键的断点在哪里？
- 哪些功能已经形成真实需求，哪些仍停留在演示？

一个好问题包含对象、时点、判断标准和决策用途。若这四项不清楚，先从上下文推断并写入范围；会实质改变结论时才询问用户。

## 2. 建立研究台账

将材料拆成证据卡，而不是边读边写正文。每张卡至少记录：

| 字段 | 要求 |
| --- | --- |
| 支持的判断 | 这条材料能证明什么，不能证明什么 |
| 观察/数据 | 原始事实，不掺解释 |
| 来源与日期 | 一手/二手、官方/独立、采集时间 |
| 口径 | 单位、分母、时间窗、样本与筛选规则 |
| 对比基准 | 同期、前代、竞品、目标值或反事实 |
| 证据类型 | 事实 / 估算 / 推断 / 假设 |
| 置信度 | 高 / 中 / 低及原因 |
| 例外 | 反例、冲突数据或适用边界 |

先合并重复证据，再寻找冲突。不同来源口径不一致时，不要取一个“看起来合理”的数；说明差异，选择更适合决策问题的口径。

## 3. MECE：同层只使用一个主轴

常用划分轴：

- 参与者：供给者 / 平台 / 消费者 / 合作方。
- 生命周期：获取 / 激活 / 使用 / 留存 / 变现。
- 用户旅程：触发 / 选择 / 执行 / 确认 / 复用。
- 能力栈：感知 / 记忆 / 授权 / 执行 / 反馈。
- 价值链：投入 / 生产 / 分发 / 消费 / 循环。
- 经济模型：规模 / 结构 / 效率 / 质量 / 可持续性。
- 时间阶段：萌芽 / 换挡 / 趋同 / 分化。
- 风险：技术 / 产品 / 生态 / 商业 / 合规。

同一层不要混用这些轴。例如“华为、影像能力、未来机会”分别是对象、能力和含义，不能成为三个并列章节。

### MECE 四问

1. 覆盖：范围内的重要事实是否都能放入某一类？
2. 重叠：同一事实是否会同时落入多个类？若会，指定主归属，其他维度改用标签。
3. 等级：各类是否处在相同抽象层级？
4. 决策相关：这个划分是否帮助回答决策问题，而不只是整齐？

真实系统往往存在交叉，MECE 不是强行把世界切干净。可用“主轴 + 交叉矩阵”表达：正文沿生命周期展开，矩阵再比较不同参与者。若边界仍不清，显式说明归类原则。

## 4. 金字塔：纵向回答“为什么”，横向做到同类归纳

### 顶层命题

总论点应同时包含判断、原因和行动含义：

> 在【范围】内，【对象】呈现【判断】；主要由【A、B、C】共同造成；因此应【行动/关注变量】。

“市场很复杂”“行业发展很快”不是命题，因为无法证伪，也不指导行动。

### 一级论据

优先控制在 3–5 个。每项必须：

- 独立回答总论点的一个“为什么”。
- 与其他项属于同一类理由。
- 可被证据验证，而非只有态度。
- 本身能继续拆成 2–4 个二级论据。

### SCQA 可用于开篇，不可替代论证

- Situation：与决策有关的共同背景。
- Complication：出现了什么矛盾或变化。
- Question：必须回答的关键问题。
- Answer：核心判断。

背景最多服务于把问题讲清；不要让读者翻过数页才见到答案。

## 5. 用三层现实校验战略判断

竞品和市场研究中，至少区分：

1. 对外叙事：官网、发布会、管理层口号声称什么。
2. 真实兑现：产品、流程或实测究竟能做什么，完成度如何。
3. 市场验证：用户是否复用、愿意付费，销量/活跃/留存是否变化。

常见高价值洞察来自三层的不一致：声量高但使用低、功能多但闭环少、销量好但并非由主叙事驱动。不要用第一层证据证明第三层结论。

## 6. 从观察推进到根因

使用以下链路，避免停在现象归纳：

> 观察 → 与基准的差距 → 近因 → 底层机制 → 战略约束 → 可干预点

示例结构：

- 观察：功能入口很多，但实际调用低。
- 差距：有供给，不等于形成需求。
- 近因：入口摩擦大、成功率低、结果不可回溯。
- 底层机制：授权、上下文与反馈链路未打通。
- 约束：继续增加功能只会扩大认知和维护成本。
- 干预：先选高价值短链路做深，再扩覆盖。

在写“导致”“证明”“根因”前，检查替代解释。至少问：是否可能由价格、渠道、品牌基本盘、样本偏差、上市时长或供给限制造成？证据只能支持相关性时，使用“伴随”“可能解释”“与……一致”。

## 7. 证据强度与结论措辞匹配

从强到弱的一般顺序：

1. 同口径行为或经营数据、可重复真机/流程实测。
2. 多个独立来源的具体反馈或一致观察。
3. 官方产品材料、管理层陈述、发布会演示。
4. 单一案例、媒体转述、模型估算、匿名爆料。

来源权威性不等于适用性：官方材料适合证明“它如何叙事”，不一定能证明“用户真正使用”。

结论措辞随证据降级：

- 高置信：显示、已形成、主要由。
- 中置信：表明、与……一致、较可能。
- 低置信：提示、可能、仍待验证。

把反例写入边界。一个经得住限制条件的窄结论，优于一个宏大但脆弱的判断。

## 8. 数字纪律

- 总量与结构并看：规模增长可能来自少数大户、批量导入或一次性活动。
- 均值与分布并看：平均安装量不能回答“多少人从未安装”。必要时看中位数、分位数、Top x% 和集中度。
- 存量与增量并看：累计量可能掩盖新供给已无生存空间。
- 声量与行为分开：播放、评论和搜索不等于购买、复用或留存。
- 结果与条件分开：渠道、供货和上市节奏可能是兑现条件，不是独立需求。
- 外推给区间：公开公式、假设、统计周和敏感性，不伪装成官方预测。

## 9. 洞察筛选

保留同时满足以下条件的洞察：

- 非显然：不是资料标题的改写。
- 可证明：至少有一条主证据和一条交叉证据，或明确标为假设。
- 有机制：能解释为什么，而不只是共现。
- 可迁移：在定义范围内不依赖单一偶发案例。
- 可决策：会改变优先级、资源配置、产品路线或验证计划。

洞察之间也要 MECE。若两条最终导向同一机制，将其合并；若一条只是另一条的例子，将其降到二级证据。
